# Sistema de Notas do Aluno

Um programa desenvolvido em Python para calcular a média final de um aluno a partir de duas notas e informar automaticamente se ele foi aprovado ou reprovado.

## Tecnologias Utilizadas

- Python 3
- Funções
- Variáveis
- Entrada de dados com `input()`
- Conversão de dados com `float()`
- Estruturas condicionais `if/else`
- Formatação de números com `f-string`

## Como Instalar e Executar

### Pré-requisitos

É necessário ter o Python 3 instalado no computador.

### Executando o projeto

1. Baixe ou clone o projeto.
2. Abra a pasta no Visual Studio Code ou outro editor.
3. Salve o código em um arquivo com extensão `.py`, por exemplo:
   `media_aluno.py`
4. Execute o arquivo pelo terminal:

```bash
python media_aluno.py
